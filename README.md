# Create-YanS-for-low-end-PCs
Сборка ютубера YanS опитимизированная для слабых пк на базе Create и Create Aeronautics

Данная сборка предназначена для слабых пк которые не могут потянуть оригинальную сборку

Тестировалась она на Ryzen 5 4600G без видеокарты и с 8ГБ ОЗУ
В самом майнкрафте стабильные 30-60 FPS что нормально для майнкрафта и сборке на 110+ модов на слабых пк

ВНИМАНИЕ данная сборка не является оффициальной и новые релизы могут выходить не сразу!!
