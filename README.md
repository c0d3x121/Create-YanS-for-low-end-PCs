# Create-YanS-for-low-end-PCs
### Сборка ютубера YanS опитимизированная для слабых пк на базе Create и Create Aeronautics

Данная сборка предназначена для слабых пк которые не могут потянуть оригинальную сборку

Тестировалась она на __Ryzen 5 4600G без видеокарты и с 8ГБ ОЗУ__
В самом майнкрафте стабильные 30-60 FPS что __нормально__ для майнкрафта и сборке на 110+ модов на слабых пк
_____________________________
Были добавлены:
* Farmer's Delight и аддоны
* Aero Engine
* Create Power Grid
* Create Transmission & Linkage
* Моды на оптимизацию
